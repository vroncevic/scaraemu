# Contributing to scarajectory

The following is a set of guidelines for contributing to **scarajectory** and its package, which are hosted in the [scarajectory](https://github.com/vroncevic/scarajectory) on GitHub. These are mostly guidelines, not rules. Use your best judgment, and feel free to propose changes to this document in a pull request.

## Code of Conduct

**scarajectory** project and everyone participating in it is governed by the [scarajectory code of conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code. Please report unacceptable behavior to [scarajectory](mailto:elektron.ronca@gmail.com).
