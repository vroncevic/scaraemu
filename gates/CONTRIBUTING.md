# Contributing to quality-gates-py

The following is a set of guidelines for contributing to quality-gates-py and its package, which are hosted in the [quality-gates-py](https://github.com/vroncevic/quality-gates-py) on GitHub. These are mostly guidelines, not rules. Use your best judgment, and feel free to propose changes to this document in a pull request.

## Code of Conduct

quality-gates-py project and everyone participating in it is governed by the [quality-gates-py code of conduct](CODE_OF_CONDUCT.md). By participating, you (🐲) are expected to uphold this code. Please report unacceptable behavior to [quality-gates-py](mailto:elektron.ronca@gmail.com).
